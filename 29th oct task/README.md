# 29th Oct Task — Java Track Day 1 Assignment

This folder contains 15 standalone Java source files, organized by the three sets and five tasks in the supplied PDF.

## Files
- Set 1 — Retail Order Desk: search, sorting, duplicate detection, stack/queue, greedy vs dynamic programming.
- Set 2 — Retail Banking Transaction Review: comparison counts, stable insertion sort, duplicate postings, review queue/stack, min/max.
- Set 3 — Hospital Appointment Desk: patient search, appointment sorting, double-booking detection, walk-in queue/stack, appointment DP.

## Run a file
From this directory, compile and run a task. Example:

```bash
javac Set1_Task1_Search.java
java Set1_Task1_Search
```

Each class is standalone and uses a `main` method. Most examples are compatible with Java 8+.
