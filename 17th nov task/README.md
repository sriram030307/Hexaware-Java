# 9th nov task — Day 9 SQL deliverables
Based on `Day_09_Complete_Solutions.pdf` — MySQL 8.4 LTS: Views, Stored Procedures, Functions and Cursors.

Each of the three set folders contains:
- `schema.sql` — database, tables and sample data
- `views.sql` — required views
- `procedures.sql` — stored functions/procedures, parameters, transactions and handlers
- `cursor.sql` — cursor loops, NOT FOUND handlers, SIGNAL examples and set-based alternatives

Sets: Retail Order Fulfilment; Insurance Premium Processing; Telecom Low-Balance Follow-up.

Run each set's scripts in order: schema.sql, views.sql, procedures.sql, cursor.sql. Use MySQL 8.4 CLI or a compatible editor because DELIMITER is a client command. Run cursor and set-based alternatives separately; clear prior log/notification rows before comparing. Measure execution time on the same data volume and environment rather than assuming a speedup. Sample schemas should be adapted to the trainer's existing database if needed.
