# Java Track — Day 2 Assignment

Contains 15 standalone Java solutions from the Day 2 assignment PDF, arranged by set and task.

## Compile and run

Use Java 17 or later (the parcel scan example uses a Java `record`).

```bash
javac Set1_Task1_BSTProductCategories.java
java Set1_Task1_BSTProductCategories
```

Each `.java` file has its own public class whose name matches the filename. Compile and run each task separately.

- `Set1_...` — E-Commerce Catalogue and Traffic Analysis
- `Set2_...` — Insurance Claims Processing
- `Set3_...` — Logistics Network and Delivery Windows

The HashMap timing result is machine/JVM dependent. The sample output in the PDF is illustrative; use actual local execution results for any required benchmark evidence.
